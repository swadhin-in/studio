# **App Name**: Swadhin's Digital Canvas

## Core Features:

- Dynamic CV Parsing: Automatically parse CV content to populate website sections, ensuring easy updates and a consistent presentation.
- AI-Powered Personalization Tool: Leverage the Gemini API to analyze user interaction data and dynamically suggest projects or skills relevant to their interests. The Gemini API acts as the reasoning tool here. 
- Interactive Project Showcase: Enable detailed project pages with integrated demos and direct links to GitHub repositories for easy access and exploration.
- Certification Verification System: A verification mechanism confirming the validity and status of certifications, enhancing credibility.
- Contact Form Integration: Implement a fully functional contact form that sends messages directly to the portfolio owner's email for easy communication.

## Style Guidelines:

- Primary color: Vivid blue (#4285F4) to evoke trust, professionalism, and technological expertise.
- Background color: Light gray (#F5F5F5) for a clean, modern look.
- Accent color: Deep violet (#673AB7) to highlight calls to action and interactive elements.
- Headline font: 'Space Grotesk' sans-serif for headlines, reflecting a tech-forward outlook.
- Body font: 'Inter' sans-serif, used in conjunction with Space Grotesk for longer text.
- Code font: 'Source Code Pro' monospace font for code snippets.
- Use minimalist, modern icons, consistent in style and weight, to enhance visual appeal without cluttering the design.
- Implement a clean, responsive layout with clear visual hierarchy to guide users through the portfolio effectively.
- Subtle animations, like smooth scrolling and hover effects, to create an engaging user experience.
